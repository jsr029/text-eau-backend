# Politique de sécurité

| Version | Supportée          |
| ------- | ------------------ |

## Signalement d'une vulnérabilité

Si tu découvres une vulnérabilité de sécurité, merci de **ne pas** ouvrir une issue publique.

Contacte plutôt les mainteneurs de manière privée (via email ou discussion privée GitHub).

Nous nous engageons à répondre rapidement et à corriger les problèmes de sécurité dans les meilleurs délais.
