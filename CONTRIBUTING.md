# Guide de contribution

Merci de vouloir contribuer à ce projet ! 🎉

## Comment contribuer

1. **Fork** le dépôt
2. Crée une branche (`git checkout -b feature/ma-fonctionnalite`)
3. Commit tes changements (`git commit -m 'Ajout de ma fonctionnalité'`)
4. Push sur la branche (`git push origin feature/ma-fonctionnalite`)
5. Ouvre une **Pull Request**

## Bonnes pratiques

- Écris des messages de commit clairs et descriptifs
- Respecte le style de code existant
- Ajoute des tests si possible
- Mets à jour la documentation si nécessaire

## Signalement de bugs

Utilise les Issues GitHub et fournis :
- Description claire du problème
- Étapes pour reproduire
- Comportement attendu vs obtenu
- Environnement (OS, version, etc.)

Merci pour ta contribution !
